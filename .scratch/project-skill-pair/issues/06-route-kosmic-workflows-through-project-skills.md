# 06 — Route Kosmic workflows through Project skills

**What to build:** Keep Kosmic as the workflow orchestrator while ensuring contributor work receives the Project's Development Skill, shared behavior comes through Usage, and Consumers can invoke Usage without entering development workflow.

**Blocked by:** 03 — Make Skill Pair publication transactional.

**Status:** done

- [x] Contributor-oriented Kosmic workflows resolve and load the canonical Development Skill.
- [x] Loading Development reliably resolves the paired Usage Skill for shared and consumer-facing guidance.
- [x] Kosmic workflow policy is not duplicated into generated Development packages.
- [x] Consumer requests can invoke the Usage Skill directly without loading specification or implementation workflow.
- [x] Missing, stale, or mismatched Skill Pairs fail clearly rather than allowing the agent to proceed without Project guidance.
- [x] A smoke scenario demonstrates contributor and consumer routing against the same generated pair.
