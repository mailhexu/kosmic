# Epic 12: Behavioral Proposal Gate

## Description

Define and enforce the baseline-versus-candidate evidence contract that replaces WikiSkill's benchmark score gate without weakening Kosmic's human review.

## Scope

### In Scope
- Candidate isolation and comparison procedure
- Behavioral evidence linkage and accepted/rejected lifecycle rules
- Task 7 proposal review integration

### Out of Scope
- Universal scalar scoring or automatic rollback
