# PRB Paper Numbers Pipeline

Create or extend a Phys. Rev. B manuscript in `/home/hexu/projects/mypapers/<name>/`.
The git repository always lives under `mypapers`; project subdirs may hold symlinks into it.

## Scaffold

```
mypapers/<name>/
├── main.tex          # revtex4-2, \input{data/numbers}
├── references.bib    # DOI- or arXiv-verified entries only
├── Makefile          # numbers target; main.pdf depends on figs
├── scripts/make_figures.py
├── figs/  data/      # generated artifacts, committed
```

## Rules

1. Hand-typed numbers are prohibited. `scripts/make_figures.py` emits
   every value as a `\newcommand` macro in `data/numbers.tex`; it is the
   single source of truth and runs the real code.
2. Write in the PRB register: present-tense method exposition and related-
   work positioning, no session or story references.
3. Cite only DOI- or arXiv-verified entries.
4. `make numbers && make` must give zero LaTeX errors and zero undefined
   citations or references, from a clean rebuild (`rm main.aux main.bbl
   main.fdb_latexmk` first).
5. Read every figure in the PDF; extraction catches broken axes.

## Makefile pattern

```make
numbers:
	source /home/hexu/projects/myenvs/mydev/bin/activate && python scripts/make_figures.py
main.pdf: main.tex references.bib data/numbers.tex figs/fig_*.pdf
	latexmk -pdf main.tex
data/numbers.tex figs/fig_%.pdf: scripts/make_figures.py
	$(MAKE) numbers
```

## Number macros and gotchas

Format a float as `f"{x:.2e}".replace("e", r"\times 10^{") + "}"`,
stripping the `+`. Prefer named macros such as `\cOne` over digits.
The first latexmk pass shows all citations undefined; later passes resolve
them. State spin-summed versus per-spin conventions explicitly. Update the
parent AGENTS.md; record the work as a kosmic quick task.
