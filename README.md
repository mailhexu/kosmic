# kosmic

Kosmic is Knowledge-oriented, spec-driven infrastructure for coding: an OpenCode skill for persistent project memory, atomic notes, and PRD -> Architecture -> Epics -> Stories workflows.

The skill identity is `kosmic` and is loaded with `/skill kosmic`. The knowledge vault directory remains `memnotes` by default so existing notes, specs, and logs keep using `./memnotes`.

See [skills/README.md](skills/README.md) for usage and task documentation.
